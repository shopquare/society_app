# Event Management — SecureGate v2

## Overview
Full event lifecycle management (`/admin/events`, `/resident/community?tab=events`, `api/community_events.php`) supporting 9 categories (Festivals, Cultural Programs, Society Meetings, Birthday Celebrations, Sports Events, Children's Activities, Community Gatherings, Annual Functions, Workshops).

## Capabilities
- Poster upload via `includes/upload_helper.php`, venue location, start/end schedule, capacity limits, optional paid registration fee tracking, and event photo gallery (`sms_event_photos`).
- Interactive Monthly Calendar + Upcoming Events list with capacity-checked registration/cancellation and `event_announcement` notifications.
